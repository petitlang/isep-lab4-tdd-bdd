# ISEP Lab 4 - TDD, BDD and GenAI in Testing

Java exercises for the Test & Test Automation lab of 16 November 2026:

- PrimeChecker: primality checks from 0 through 100.
- FizzBuzz: string representations from 1 through 100.
- RomanNumerals: Gherkin/Cucumber scenarios from 1 through 1000.

Development follows Red (a new failing test), Green (the smallest passing implementation),
and Blue (refactoring with tests still green). Stage commits record actual test runs.

## Requirements

JDK 17 or newer. Maven Wrapper will be included so that a separate Maven installation is not required.
